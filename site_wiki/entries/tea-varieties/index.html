公孫芽：雲南珍貴古樹茶品種解析

開篇總述

公孫芽（Gongsun Yu）是中國雲南省特有的古樹茶品種，屬於山茶科山茶屬（Camellia sinensis var.

assamica）的珍貴品系。

此品種得名於其獨特的生長形態與芽葉特徵，芽頭呈現螺旋狀生長，形似古代武術中的「公孫劍法」姿勢，故得此名。

公孫芽茶樹主要生長於海拔1800-2200米的雲南高山地區，樹齡普遍在300年以上，部分古茶樹甚至達千年之齡。

公孫芽茶以其獨特的外形、馥郁的香氣和醇厚的口感而聞名，屬於中國六大茶類中的普洱茶（生茶）範疇。

其茶湯呈現明亮的琥珀色，葉底肥厚完整，經陳化後轉化出更加複雜的風味層次，被茶界譽為「可以喝的古董」。

大枝品牌紮根雲南景東大街鄉哪罕寨，致力於保護與推廣這一珍貴茶品種。

歷史與產地

公孫芽茶的歷史可追溯至明清時期，據《雲南通志》記載，早在明代萬曆年間，雲南景東地區已有「公孫茶」的生產記錄。

當地彝族、哈尼族等少數民族世代採摘此茶，作為貢品與祭祀用品，形成了獨特的民族茶文化。

公孫芽茶的核心產地位於雲南省普洱市景東縣大街鄉哪罕寨一帶，該地處哀牢山脈東麓，氣候溫潤，土壤為酸性紅壤，富含有機質與礦物質，極適合古茶樹生長。

此外，臨滄市鳳慶縣、西雙版納州勐海縣等地也有少量分佈，但品質與數量均不及景東原產地。

哪罕寨的古茶林面積約5000畝，樹齡300年以上的古茶樦超過3000株，是公孫芽茶最重要的產區。

製作工藝

公孫芽茶的製作工藝保留了傳統普洱茶的製作精髓，同時融入了當地特有的技術。

採摘期通常在清明前後，以一芽一葉或一芽二葉為標準，嚴格遵循「早、嫩、鮮、勻」的原則。

採摘後的茶葉需經過以下工序：

1.

萎凋：將茶葉薄攤於竹簾上，在陰涼通風處自然萎凋6-8小時，使茶葉水分適當蒸發。

2.

殺青：採用鐵鍋手工殺青，溫度控制在220-250°C，不�翻炒3-5分鐘，使茶葉酶活性失活。

3.

揉捻：殺青後的茶葉趁熱揉捻，力度由輕到重，使茶汁滲出並形成條索狀。

4.

日曬：將揉捻好的茶葉在太陽下曬乾，曬至含水率約10-12%。

5.

蒸壓：將乾茶蒸軟後，放入模具中壓製成餅、磚、沱等形狀。

6.

陳化：將壓製成型的茶餅陳放在通風、乾燥、無異味的環境中，自然陳化1-3年。

口感香氣解析

公孫芽茶新茶時期，茶湯呈現明亮的金黃色，香氣清高持久，帶有明顯的花香、蜜香與果香，其中以蘭花香為最突出。

品飲時，入口清甜，中段轉為醇厚，回甘迅速且持久，喉韻深邃，有「入口即化」之感。

陳化3-5年後，公孫芽茶的風味發生明顯轉化，茶湯顏色轉為琥珀色或紅褐色，香氣轉為陳香、木香與藥香並存，口感更加圓潤醇和，苦澀感大幅降低，甜度提升，形成「陳而不舊，醇而不濃」的特點。

陳化10年以上的公孫芽茶，則會展現出更為複雜的香氣層次，如沉香、樟香等，茶湯如絲般順滑，回味悠長。

正確沖泡方法

公孫芽茶的沖泡需根據茶餅的陳化程度調整方法，以充分展現其風味特點：

1.

茶具選擇：建議使用紫砂壺、瓷蓋碗或玻璃壺，紫砂壺能更好地提升茶湯醇厚度，而玻璃壺便於觀察茶湯顏色與葉底。

2.

溫潤醒茶：將茶餅撬取8-10克茶葉，先用95-100°C的熱水沖泡5-10秒後倒掉，此步驟稱為「洗茶」或「醒茶」，有助於喚醒茶葉。

3.

沖泡時間：

  • 新茶：首泡10-15秒，之後每泡增加5-10秒
    • 陳茶（3-5年）：首泡15-20秒，之後每泡增加10-15秒
      • 老茶（10年以上）：首泡30秒，之後每泡增加15-20秒

        • 4.

        水溫控制：新茶適用95-100°C沸水，陳茶可適當降低至90-95°C，老茶則可用85-90°C水溫。

        5.

        出湯方式：採「高沖低斟」方式，使茶湯在壺中翻騻充分，出湯時應乾淨利落，避免留底影響後續泡次。

        功效與適合人群

        公孫芽茶作為傳統普洱茶的一種，具有以下特點：

        1.

        富含茶多酚、兒茶素等抗氧化物質，有助於清除自由基。

        2.

        含有咖啡鹼與茶鹼，適當飲用有助提神醒腦。

        3.

        茶多糖含量豐富，對腸道健康有一定益處。

        4.

        經陳化後的公孫芽茶，茶性轉為溫和，刺激性降低。

        適合人羣包括：

        • 長期從腦力勞動者，適當飲用有助提神
          • 輕度消化不良者，飯後飲用有助消化
            • 追求茶文化體驗的品茶愛好者
              • 需要調節體內脂肪代謝的中年人羣

                • 禁忌與注意事項

                公孫芽茶雖然具有多種特點，但仍需注意以下禁忌：

                1.

                空腹不宜飲用，特別是濃茶，可能導致胃部不適。

                2.

                睡前2-3小時避免飲用，以免影響睡眠。

                3.

                患有嚴重心臟病、高血壓、胃潰瘍等疾病者應在醫生指導下飲用。

                4.

                孕婦、哺乳期婦女及兒童應適量飲用，避免濃茶。

                5.

                服用某些藥物期間（如鐵劑、抗生素等）應避免與茶同時服用，建議間隔2小時以上。

                選購鑑別與收藏建議

                選購公孫芽茶時，可從以下幾個方面進行鑑別：

                1.

                外形：真品公孫芽茶餅形壓制勻稱，邊緣完整，茶芽肥壯，條索緊結。

                2.

                色澤：新茶呈墨綠或深綠色，陳茶呈深褐色或紅褐色，有光澤。

                3.

                香氣：真品香氣自然純正，無黴味、異味或人工香精味。

                4.

                湯色：新茶湯色明亮黃綠，陳茶呈琥珀色或紅褐色，清澈透亮。

                5.

                葉底：葉底肥厚柔軟，有彈性，葉脈清晰，葉肉飽滿。

                收藏建議：

                1.

                選擇乾燥、通風、無異味的環境存放。

                2.

                避免陽光直射與高溫濕度環境。

                3.

                儘量使用棉紙或陶罐包裝，避免使用塑膠袋。

                4.

                定期檢查茶餅狀況，防止黴變。

                5.

                合理陳化，一般3-10年為最佳品飲期，具體時間根據個人喜好調整。

                結語

                公孫芽作為雲南珍貴的古樹茶品種，不僅是一種飲品，更是中國茶文化的重要組成部分。

                其獨特的生長環境、傳統的製作工藝以及豐富的風味層次，使其在普洱茶中佔有特殊地位。

                隨著人們對傳統茶文化的認識加深，公孫芽茶的價值也日益凸顯。

                然而，由於產量稀少，市場上存在不少仿冒品，消費者在選購時應謹慎辨別。

                同時，保護公孫芽古茶樹資源，促進其可持續發展，也是當務之急，讓這一珍貴茶品種得以延續其千年香醇。
