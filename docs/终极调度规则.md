# dazi.uk 全站 AI 自动发文终极调度规则（已落地）

## 一、触发时间与模型

- GitHub Actions：`cron: '0 22 * * *'`（UTC 22:00 = 昆明/北京次日 06:00）。
- 模型：**只用智谱 GLM**，默认 `glm-4-plus`；可用环境变量 `ZHIPU_MODEL` 覆盖为其它智谱模型。
- 没有 `ZHIPU_API_KEY` 时脚本直接报错停工，**不生成、不落盘、不制造假数据**。
- 生成流程：调用 → 确定性归一化 → 校验 → 不合格把错误回喂模型重试（最多 3 次）→ 仍不合格则整批中止，不写入任何文件。

## 二、三站分工

| 目标 | 频率 | 产物 | 落盘位置 | 部署 |
|---|---|---|---|---|
| `wiki.dazi.uk` | 每日 1 条 | 标准化茶百科词条（繁中 + EN，固定九段式） | `content/wiki/{en,zh}/` | `site_wiki/` → CF Pages `wiki-dazi-uk` |
| `new.dazi.uk/knowledge.html` | 每日 1 条 | 茶知识科普（繁中 + EN，标注来源） | `content/knowledge/*.json` | `site/data/knowledge-latest.json` + `site/knowledge-inject.js` |
| `blog.dazi.uk` | 每周一、周四各 1 篇 | 「景东大街乡哪罕」深度 SEO 数据博文（繁中 + EN） | `content/{en,zh}/` | `site/` → CF Pages `dazi-encyclopedia` |

想临时只补跑某一类：`python scripts/daily_post.py wiki|knowledge|seo`。

科普选题固定取自 `https://new.dazi.uk/knowledge.html` 背后的 `data/knowledge.js`：每次运行先刷新 474 条知识库（`docs/knowledge-library.json`），再从**未用过**的来源条目生成当日科普；抓取失败时沿用本地副本，不中断其它任务。产物保留原来源标题与 URL，并通过 `knowledge-inject.js` 回灌到该站列表顶部。

## 三、固定 SEO 标准（已在生成与校验中强制）

- Title：**50–60 字符**；英文标题含 `Jingdong` / `Dajie Township` / `Nahang`，繁中含「景東」「大街鄉」「哪罕」。
- Meta Description：**120–150 字符**（中英均适用）。
- 固定图片 ALT：
  - 繁中：`景東大街鄉哪罕那罕古樹茶倉儲數據記錄`
  - 英文：`Nahang ancient tea storage data, Dajie Township Jingdong Yunnan`
- 开篇定位句：
  - 繁中：`哪罕（亦作那罕），隸屬於雲南景東縣大街鄉，英文 Nahang。`
  - 英文：`Nahang (那罕) is a village in Dajie Township, Jingdong County, Yunnan, China.`
- 关键词池全覆盖：景东 / 大街乡 / 哪罕 / 那罕 / Nahang / 景东大街乡普洱茶（英文版用对应译名 + 原词保留）。
- 内链：每篇哪罕系列文章页自动列出**全部往期**哪罕系列文章，繁中链繁中、英文链英文。
- 数据纪律：只写「记录方法/字段」，禁止编造检测值、认证、法规数字。
- 健康纪律：只谈日常饮用与滋味，必须写明「茶是日常饮品，不能替代药物或治疗」。

## 四、5 篇繁体禅茶精做文章

已导入 `content/zh/`，统一归入 `journal`（品牌初心·茶山纪实）栏目，保留原「四段 + FAQ」体例：

- `morning-mist-original-tea.md`
- `fresh-leaf-to-dry-tea.md`
- `tea-flower-bee-ecology.md`
- `zen-tea-simple-cup.md`
- `four-seasons-pest-observation.md`

校验器对 journal 栏目放宽九段式，但结构、繁体、禁用词、封面仍强制校验。

## 六、需要人工完成的两件事

1. **Workflow 上传**：当前 GitHub Token 缺 `workflow` scope，无法写入 `.github/workflows/`。
   仓库根目录已备好 `daily-post.workflow.yml`，请手动放到 `.github/workflows/daily-post.yml`，或提供有 workflow 权限的 Token。
2. **域名绑定**：CF Token 无 DNS 权限且 Pages API 对 `.uk` 报 invalid TLD，请在 Cloudflare Dashboard 手动把
   `blog.dazi.uk`、`wiki.dazi.uk` 绑定到对应 Pages 项目。
3. **科普站注入**：`new.dazi.uk/knowledge.html` 不在本仓库。把
   `https://blog.dazi.uk/knowledge-inject.js` 以 `<script>` 追加到其 `data/knowledge.js` 之后即可自动置顶当日科普；
   若有该站仓库权限，也可把 `site/data/knowledge-latest.json` 的条目合并进其 `data/knowledge.js`。
