# dazi.uk 全站 AI 自动发文终极调度规则（已落地）

## 一、触发时间与模型

- GitHub Actions：`cron: '0 22 * * *'`（UTC 22:00 = 昆明/北京次日 06:00）。
- 模型：**只用智谱 GLM**，默认 `glm-4-plus`；可用环境变量 `ZHIPU_MODEL` 覆盖为其它智谱模型。
- 没有 `ZHIPU_API_KEY` 时脚本直接报错停工，**不生成、不落盘、不制造假数据**。
- 生成流程：调用 → 确定性归一化 → 校验 → 不合格把错误回喂模型重试（最多 3 次）→ 仍不合格则整批中止，不写入任何文件。

## 二、三站分工与素材来源

| 目标 | 频率 | 素材来源 | 产物 | 落盘位置 |
|---|---|---|---|---|
| 茶百科词条（双语） | 每日 1 条 | **`wiki.dazi.uk`** → `cha-wiki-mirror` 的 11,824 条词条索引 | 标准化茶百科词条（繁中 + EN，固定九段式） | `content/wiki/{en,zh}/` |
| 生活化茶经验（双语） | 每日 1 条 | **`new.dazi.uk/knowledge.html`** → `data/knowledge.js` 的 474 篇 | 生活化茶经验科普（繁中 + EN，标注来源） | `content/knowledge/*.json` |
| `blog.dazi.uk` | 每周一、周四各 1 篇 | 茶园自有记录 | 「景东大街乡哪罕」深度 SEO 数据博文（繁中 + EN） | `content/{en,zh}/` |

想临时只补跑某一类：`python scripts/daily_post.py wiki|knowledge|seo`。

### 素材源纪律（重要）

- **`wiki.dazi.uk` 与 `new.dazi.uk/knowledge.html` 是既有的正式站，只读、不改写、不改域名。**
  脚本只从它们取素材，产出落在 `blog.dazi.uk` 体系内；不覆盖、不劫持原站内容。
- wiki 词条素材：运行 daily 时用 `GH_TOKEN` 从 `hanchaoqun8/cha-wiki-mirror` 的
  `website/data/tea-wiki-kb.json` 刷新索引（`docs/wiki-source.json`），按 blob SHA 判断是否需要重下，
  失败则沿用仓库内已提交索引。只取**词条名 / 分类 / 短摘要 / 原文链接**，不下载原文正文。
- 版权遵守素材站声明 `content-signal: search=yes, ai-train=no, use=reference`：
  智谱只参考事实，**不得照抄原句**；每篇词条的 `source_note` 必须写明
  `Facts referenced from wiki.dazi.uk and rewritten independently. Source: https://wiki.dazi.uk/e/<slug>`。
- 科普素材：每次运行先从 `https://new.dazi.uk/data/knowledge.js` 刷新 474 篇（`docs/knowledge-library.json`），
  再从**未用过**的条目生成当日科普；写法要求「更生活化」——日常冲泡、存放、滋味等场景，
  像茶友之间的短札，不做百科腔、不做广告腔。产物保留原来源标题与 URL。
- 两个素材源各自维护已用清单（`used_wiki_sources` / `used_knowledge_sources`），互不串号。

## 三、固定 SEO 标准（已在生成与校验中强制）

- Title：**50–60 字符**；英文标题含 `Jingdong` / `Dajie Township` / `Nahang`，繁中含「景東」「大街鄉」「哪罕」。
- Meta Description：**120–150 字符**（中英均适用）；不足时按「来源摘要 → 品牌说明 → 中性说明」补足，
  禁止同一句重复三遍凑字数。
- 固定图片 ALT：
  - 繁中：`景東大街鄉哪罕那罕古樹茶倉儲數據記錄`
  - 英文：`Nahang ancient tea storage data, Dajie Township Jingdong Yunnan`
- 开篇定位句：
  - 繁中：`哪罕（亦作那罕），隸屬於雲南景東縣大街鄉，英文 Nahang。`
  - 英文：`Nahang (那罕) is a village in Dajie Township, Jingdong County, Yunnan, China.`
- 关键词池全覆盖：景东 / 大街乡 / 哪罕 / 那罕 / Nahang / 景东大街乡普洱茶（英文版用对应译名 + 原词保留）。
- 内链：每篇哪罕系列文章页自动列出**全部往期**哪罕系列文章，繁中链繁中、英文链英文。
- 语言守卫：英文文章的 title / description / cover_alt 不得混入中文字符（素材标题是中文，模型易照抄）。
- 数据纪律：只写「记录方法/字段」，禁止编造检测值、认证、法规数字。
- 健康纪律：只谈日常饮用与滋味，必须写明「茶是日常饮品，不能替代药物或治疗」。
