# 茶葉百科示範文章寫作規範（雙語）

## 硬性要求
- 每篇**英文版**放 `content/en/<slug>.md`，**繁中版**放 `content/zh/<slug>.md`， slug 相同。
- 两语内容**对应**（同一主题、同一结构），但各自地道，不是逐字翻译。
- 每篇 1000–1200 字（中文字数；英文 700–900 words）。
- 繁中版**全程繁体**，禁止简体字，禁止「哪罕村」（用「哪罕寨」）。

## Front matter（确切格式）
```
---
title: "文章标题（英文版英文 / 繁中版繁中）"
slug: "english-slug"
date: "2026-11-18"
category: "栏目id"
description: "150-160字符的摘要（对应语言）"
cover: "英文版用 tea 图库文件名；繁中版同样"
---
```
- `category` 只能是：`varieties` / `brewing` / `wellness` / `buying` / `culture` / `teaware` / `journal`
- `cover` 从以下图库选（真实存在的）：`ancient-tea-tree.jpg`, `morning-mist-garden.jpg`, `hands-fresh-leaves.jpg`, `bamboo-tray-withering.jpg`, `dry-tea-closeup.jpg`, `pour-tea-glass.jpg`, `pour-tea-rock.jpg`, `tea-flower-bee.jpg`, `bird-nest-eggs.jpg`, `rainbow-over-garden.jpg`, `farmer-on-path.jpg`, `tea-cake-poster.jpg`

## 固定 9 段式结构（每篇必须有这 9 个 ## 二级标题）
英文版：
```
## Overview

## Craft & Processing
## Appearance, Aroma & Taste
## How to Brew
## Benefits & Who It Suits
## Cautions & Considerations
## Buying, Authentication & Storage
## Final Thoughts
```
繁中版：
```
## 開篇總述

## 結語
```

## 合规底线（必须遵守）
- 「功效」部分只做**客观、克制的科普**：描述成分（茶多酚、咖啡碱、氨基酸等）与饮用感受，**禁止**任何治病、疗效、夸大宣传（降血压/减肥/排毒/抗癌/增强免疫力等词禁用）。要写明「茶是日常饮品，不能替代药物或治疗」。
- 历史/产地不虚构精确数据（海拔、年份、产量），用可信的表述。
- 文化客观、专业，百科式语气。

## 文风
- 专业权威、结构清晰、段落均匀、适合 SEO 收录。
- 英文地道，符合海外茶博客风格；繁中专业、雅洁。
